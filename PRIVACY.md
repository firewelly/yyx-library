## 中文版

### 一、总则

YYX书库是一款**本地部署的书库管理与阅读工具**，运行于用户自有的 UGOS Pro / fnOS NAS 设备上。
我们高度重视你的隐私：**本应用不收集、不上传、不共享任何个人数据**。

### 二、我们不收集的信息

本应用**不会**收集、上传或向任何第三方提供以下信息：

- 个人身份信息（姓名、手机号、邮箱、账号密码等）；
- 设备信息（序列号、MAC 地址、位置信息等）；
- 阅读数据（书库内容、阅读记录、书签、笔记等）；
- 使用统计（崩溃日志、埋点数据、行为分析等）。

### 三、数据存储位置

本应用产生的全部数据均保存在**你自己的 NAS 设备上**：

| 数据 | 存储位置 | 说明 |
|------|---------|------|
| 书库数据库（书籍/章节） | 你指定的书库路径（如 `/volume1/books/novelmgt.db`） | 只读方式访问，应用不会修改 |
| 阅读进度 / 书签 / 笔记 | 本应用数据目录下的 `novelmgt_state.db` | 仅存于你的设备，供你的多台设备同步读取 |
| 应用配置 | 本应用数据目录 | 仅存于你的设备 |

### 四、网络访问说明

应用仅在以下场景产生网络行为，且全部限定在**你的局域网内部**：

1. **书库读取**：浏览器访问 NAS 上本应用提供的 Web 界面与书库文件（HTTP/HTTPS，局域网或你自行配置的远程访问通道）；
2. **阅读进度同步**：你的多台设备访问同一 NAS 上的状态接口，同步进度/书签/笔记；
3. 若你在"爬虫"功能中主动配置书源抓取小说，应用会访问**你指定的目标网站**——该行为由你主动发起，与本应用开发者无关。

**除上述行为外，本应用不进行任何外部网络通信。**

### 五、第三方组件

本应用基于 Flutter 及若干开源组件构建（详见应用内「关于」页与源码仓库），
这些组件均为本地运行库，**不包含任何数据采集或上报逻辑**。

### 六、你的权利

由于所有数据均存储在你的设备上，你对自己的数据拥有完全控制权：

- 随时查看、导出、修改、删除书库与阅读数据；
- 卸载应用即可移除应用数据（书库文件由你自行保留或删除）。

### 七、政策变更

若本政策发生变更，我们将在源码仓库与后续版本说明中公示。

### 八、联系我们

如对本隐私政策有任何疑问，请联系：menglong_yuan@126.com

## English Version

### 1. Overview

YYX Library is a **self-hosted library management and reading tool** that runs entirely on your own
UGOS Pro / fnOS NAS device. We take your privacy seriously: **this app collects, uploads, and shares
no personal data whatsoever.**

### 2. Information We Do NOT Collect

This app does **not** collect, upload, or share with any third party:

- Personal identity information (name, phone, email, passwords, etc.);
- Device information (serial numbers, MAC addresses, location, etc.);
- Reading data (library contents, reading history, bookmarks, notes, etc.);
- Usage analytics (crash reports, telemetry, behavioral analytics, etc.).

### 3. Where Your Data Lives

All data generated by this app stays on **your own NAS device**:

| Data | Location | Notes |
|------|----------|-------|
| Library database (books/chapters) | The path you specify (e.g. `/volume1/books/novelmgt.db`) | Accessed read-only; the app never modifies it |
| Reading progress / bookmarks / notes | `novelmgt_state.db` in the app data directory | Stored only on your device, shared across your own devices |
| App configuration | App data directory | Stored only on your device |

### 4. Network Activity

The app communicates on the network only in the following cases, all confined to **your local network**:

1. **Library access**: your browser accesses the web UI and library files served by this app on your NAS
   (HTTP/HTTPS over your LAN or a remote-access tunnel you configure yourself);
2. **Progress sync**: your own devices read/write progress, bookmarks and notes via the state API on the same NAS;
3. If you actively configure and run the "crawler" feature, the app will access **the websites you specify** —
   this is user-initiated and unrelated to the developer.

**Beyond the above, this app performs no external network communication.**

### 5. Third-Party Components

This app is built on Flutter and several open-source components (see the in-app "About" page and the
source repository). These are local runtime libraries and **contain no data collection or reporting logic**.

### 6. Your Rights

Because all data is stored on your device, you have full control over it:

- View, export, modify, or delete your library and reading data at any time;
- Uninstalling the app removes app data (your library files are yours to keep or delete).

### 7. Changes to This Policy

Any changes to this policy will be announced in the source repository and release notes.

### 8. Contact

For questions about this privacy policy, contact: menglong_yuan@126.com
