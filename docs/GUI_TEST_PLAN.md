# YYX书库 GUI 测试计划（最完整版）

**被测对象**：YYX书库 Web/NAS 形态（Flutter Web + Python 服务端，部署于 DXP4800
`http://192.168.3.146:12702`），以及同一代码的桌面端。
**驱动方式**：Playwright（Chromium）驱动真实部署应用——hash 路由导航、实测锚点坐标点击、
DOM input 输入（Flutter Web 文本框为真实 DOM 节点）、`/api/*` 服务端状态断言、截图取证。
**框架**：`tool/gui_tests/`（`python3 run_suite.py [--base URL] [--view desktop|mobile] [--only 模块]`）
**证据**：`tool/gui_tests/reports/<时间戳>/`（report.md + 每用例截图）。

> Flutter Web 为 canvas 渲染，无 DOM 控件树（语义树在本版本无法编程启用），
> 因此页内按钮交互采用**锚点坐标**（`anchors.py`，按视口标定）；文本输入用 DOM input；
> 断言优先用 **/api 服务端状态**（与 UI 无关的真值），截图作人工复核证据。
> UI 布局变更后需重新标定 `anchors.py`（跑 `run_suite.py --calibrate` 输出标注截图）。

## 优先级与覆盖范围

- **P0**：核心阅读闭环 + 数据安全（导入/进度/删除），每次发版必跑
- **P1**：管理功能（标签/统计/作者/设置/搜索筛选），发版必跑
- **P2**：边缘与降级场景，回归抽查

平台矩阵：`D`=桌面 1440×900，`M`=手机 390×844，`L`=横屏 844×390。

## 已知约束

1. 页内按钮坐标锚点随布局变化需重标定（`--calibrate` 出标注图；改动 UI 时同步 `anchors.py`）；
2. 阅读主题/字号等客户端持久化设置存于浏览器 IndexedDB/Hive，无 API 断言，用像素采样；
3. demo 模式导入的书随容器重建丢失——测试自带数据自清理（导入→断言→DELETE /api/books）。
