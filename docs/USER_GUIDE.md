# NovelMgt 用户指南

跨平台小说管理器（Windows / macOS / Linux / Web）：书架管理、阅读、导入导出、书库扫描、繁简转换、多编码支持、跨系统共享书库。

## 快速上手（三步）

1. **导入小说**：首页 →「导入」（Ctrl+I）
   - 选择文件：TXT / EPUB / PDF（文字版）/ MOBI / AZW3，浏览器端同样可用
   - 选择文件夹：批量导入整个目录（桌面端）
   - 没有文件？「手动添加」先建档
2. **开始阅读**：点书进详情 → 点章节。方向键翻章，Ctrl+加/减 调字号
3. **书库扫描**（推荐）：设置 → 书库文件夹 → 添加文件夹（填 `novels`、`H` 这类相对路径即可）→ 首页「扫描书库」自动导入新书、追更章节（OneDrive 占位文件自动跳过，不触发云端下载）

## 跨系统共享书库（重点）

多台设备（如 Windows + macOS）共用同一个书库：

| 步骤 | 操作 | 说明 |
|---|---|---|
| ① 共享数据库 | 两台设备：设置 → 数据库路径 → 指向同步盘上同一个 `novelmgt.db` | OneDrive/NAS 均可 |
| ② 相对路径文件夹 | 两台设备：设置 → 书库文件夹 → 手填 `novels`、`H` | 以**程序所在目录**为基准；把程序放在与 `novels/`、`H/` 同级的目录 |
| ③ 存量迁移 | 任意一台：设置 → 书库根目录 → 选项目根目录 → 弹窗勾选检测到的旧系统路径前缀 → 转换 | 库里已有的绝对路径（如 Mac 的挂载路径）会自动识别并转为相对形式 |

之后两台设备看到的是同一个书架、同一份进度。书籍路径在库里存 `novels/xxx.txt` 形式，各系统按本机基准解析。

## 阅读器

- **翻章**：方向键 / 底部按钮；**字号**：Ctrl+加/减
- **繁简切换**：顶栏 🌐 菜单 → 原文 / 简体 / 繁体（词组级 OpenCC 转换，如「头发→頭髮」）
- **章节搜索**：顶栏放大镜（简繁同搜：查「小说」可命中「小說」）
- 书签 / 笔记 / 阅读主题（纸张/米黄/暗黑/护眼绿）见顶栏
- 设置 → 阅读设置里可调字体、边距、行距、主题、繁简默认值

## 导入与编码

- TXT 自动探测编码：UTF-8 → GBK/GB18030 → Big5
- 乱码时：设置 → 导入设置 → TXT 默认编码 → 手动指定（如 GBK）→ 重新导入
- 导入会按「书名+作者」查重：同书再次导入=追更（只补新章节），不会重复建档

## 导出与备份

- **导出**：书详情 → 导出（TXT/EPUB/PDF）；首页选择模式可批量导出。桌面端选目录写文件；Web 端浏览器下载
- **备份/恢复（桌面）**：设置 → 备份数据库（复制 .db 文件，自动保留最近 7 份）
- **备份/恢复（全平台）**：Web 端为「下载 SQL / 上传 SQL」；SQL 文件可在 Web ↔ 桌面之间互导，也是跨端迁移格式

## 书库扫描细节

- 遍历配置的所有文件夹（可多个），新文件自动导入，文件有更新的自动追更
- OneDrive 未物化（占位）文件自动跳过，绝不触发云端下载（macOS 用 `du -ak` 检测）
- 0 字节文件、`.bak`、Finder 冲突副本自动忽略

## 常用快捷键（首页）

Ctrl+F 搜索 · Ctrl+I 导入 · Ctrl+S 设置 · Esc 清空搜索/返回

## 数据存放位置

| 数据 | 位置 |
|---|---|
| 书库数据库 | 默认本机应用目录；可自定义到同步盘（共享方案见上） |
| 设置（主题/文件夹/编码等） | 本机（Hive），各设备独立 |
| Web 端数据 | 浏览器 IndexedDB（清站点数据会丢失，请定期导出 SQL 备份） |
